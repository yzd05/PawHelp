# ADR 0003：指纹锁定的双层校准证据门控、Jev 概率分流与意图复核负向实验裁决

- **状态**：已采纳（证据充分性接入 Jev；意图复核经实证否决不接入）
- **日期**：2026-10-21（2026-11-17 增补特征权重边界与独立留出集隔离说明）
- **关联模块**：`app/knowledge/confidence.py`、`app/knowledge/jev_evidence.py`、`app/knowledge/pipeline.py`、`config/evidence-calibration.json`、`config/jev-evidence-calibration.json`、`evals/README.md`

## Context（背景与问题）

电商客服 RAG 必须在“严防库外编造（Out-of-Scope Hallucination）”与“控制单轮核验延迟及模型成本”之间建立可证伪的工程闭环：

1. **单层重排分数的盲区**：Cross-Encoder 分数衡量单块相关性，但面对多要点组合题或缺失前置型号条件时，
   Top-1 高分块仍可能不足以支撑完整回答。
2. **全量通用大模型核验的成本与延迟**：若每轮通过粗筛的请求都调用一次通用 LLM 做结构化充分性核查，
   将普遍增加数千毫秒首字等待与可观 Token 开销。
3. **代码与文档演进导致静默失准**：切块规则、查询改写提示词、重排超参或 Markdown 知识文档一旦改动，
   历史校准阈值的分数分布即刻漂移，继续静默沿用会造成不可知的误放或误拒。

## Decision（核心决策）

### 1. 第一层：SHA-256 `scoring_fingerprint` 硬锁定的相关性预筛

- **冻结 v2 评分公式**：`score = 0.60 * top1 + 0.25 * min(sum(scores)/3, 1.0) + 0.15 * (top1 - top2)`
  （`app/knowledge/confidence.py:32-41`）。按线上真实路径（改写 + 拆分 + 全库检索）在 72 题训练集选定阈值
  `0.174`，**24 题独立留出验证集**实现 `0/24` 误收、有用召回 `0.95`。
- **全输入哈希防漂移自锁**：`scoring_fingerprint` 联合哈希 `knowledge/**/*.md` 全文（LF 归一化）、
  6 个检索核心模块源码、`QUERY_UNDERSTANDING_SYSTEM_TEMPLATE` 与 10 项检索超参，同时**刻意解耦聊天生成模型
  `openai_model`**，使切换任意对话模型均能开箱共享校准门控；任一受控输入变更即自动退回未校准保护态并告警。
- **不在重排层叠加启发式加权**：`> [!IMPORTANT]` 关键条款与同章节邻接链表已打通解析与后台统计，但在当前
  97 块语料（600-token 按节切块已自包含限制条件）下刻意不对重排分做启发式加分，保持已校准分数分布纯粹。

### 2. 第二层：TypeSafe Jev（System-One）双边界概率分流 + LLM 兜底

| 评估维度 | 全量通用 LLM 核验 | Jev 概率分流 + LLM 中间带兜底 |
|---|---|---|
| 充分性核验 LLM 调用占比 | 100%（403/403） | **7.7%**（仅 31 题进中间带，Jev 直接决定 **92.3%**） |
| 单次判定延迟 / 499 题核验成本 | 数秒级 LLM 结构化输出 | **P50 340 ms**（P95 2758 ms）/ 60.1 万输入 token **~$0.0252** |
| 独立留出验证集表现（Hold-out） | 77 题线上验证 0 误放、0 误拒 | 99 题准确率 **0.980**（AUC **0.999**）；77 题线上验证直接分流 **93.5%**，**0 误放、0 误拒** |
| 500 题全流水线端到端表现 | 库外拒答 90/90，误拒 18/410 | 库外拒答 **90/90**，Faithfulness **0.995**，可答题误拒 **17/410** |

- **严格留出切分与安全回退**：事前锁定题号末位 `0/5` 的 99 题为独立留出集，仅用 399 道训练题选出保守阈值
  `P <= 0.05` 直接拒答、`P >= 0.60` 直接放行（`app/knowledge/jev_evidence.py:121-136`）。
- **零侵入旁路采样与故障兜底**：
  - `EVIDENCE_JUDGE=llm`（默认）：纯本地 + 通用大模型核验，无需额外第三方密钥；
  - `EVIDENCE_JUDGE=shadow`：并发竞速采集 Jev 概率日志，仅在 Jev 先于 LLM 完成时记录，超时立即通过
    `try/finally` 执行 `cancel() + await` 安全回收后台任务，对线上延迟零放大；
  - `EVIDENCE_JUDGE=jev`：当 `instructions_sha256` 失配、模型版本不一致或请求超时报错时，自动无缝回退给 LLM。

### 3. 实证否决项：199 道边界题意图复核负向实验（不接入生产）

- 在 199 道单轮口语/边界意图集（含 44 道人工逐条定稿，事前固定 36 题验证集）上实测用 Jev 替代大模型自报
  `confidence < 0.55` 复核信号（`reports/jev-intent/jev-intent-20261021.md`）。
- **否决依据**：验证集上 Jev 规则与原规则完全打平（均为错答 5 次、多澄清 3 次）。根因是**大模型判错意图时
  普遍自报 `0.72~0.93` 高置信度，症结在于业务边界定义而非概率校准**。顺着错题修补 `INTENT_PROMPT`（区分
  “改密码归咨询”与“账号被盗冻结归人工”）后直接消除了系统性偏差。因无独立实证正收益，果断拒绝为炫技接入。

## Trade-offs & Rejected Alternatives（权衡与被否决方案）

- **保守门控的误拒折中**：`90/90` 库外零编造的代价是 17 道可答题（4.1%）被偏严误拒（13 道极短口语问法重排分
  落在 `0.127~0.174` 交叠区，4 道在 Jev 中间带被 LLM 判不足）。通过拒答气泡必带`转人工 / 建工单`按钮兜底。
- **校准样本边界坦承**：Jev 放行线 `0.60` 受训练集单道边界库外题 `D9 (P=0.60)` 约束，余量较窄，故强制绑定
  `model + instructions_sha256` 防止跨版本静默失效。

## 100+ QPS Production Evolution（百级并发生产演进）

1. **外置 API 熔断与本地小模型蒸馏**：公网高并发下为 `AsyncTypeSafeClient` 增加滑动窗口错误率与尾延迟熔断器，
   外部抖动时瞬时降级至本地蒸馏的轻量 Cross-Encoder / DeBERTa 充分性分类头。
2. **基于 `shadow` 旁路的线上无损重校准**：利用零延迟增量 `shadow` 日志持续收集真实脱敏难例与负样本，
   将留出验证集从百题级扩展至千题级真实流量分层基准。
